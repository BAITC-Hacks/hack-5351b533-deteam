# Разбор шаблонных диалогов по ходам

Как читать: что сказал клиент, что решил роутер, какие инструменты вызвались, откуда взялся ответ. Полные события в [/fixtures/sessions](../../fixtures/sessions).

«Шаблон» значит ответ без вызова LLM, из slots.json или scenarios.json. «LLM» значит ответ сгенерирован по результатам действий и базе знаний. «Без роутера» значит сработал детерминированный fast path.

## Какие ещё бывают ходы

| Ситуация | Что увидит фронт |
|---|---|
| Вне области («кредит на машину») | `SYS_OUT_OF_SCOPE`, `decision = out_of_scope`, шаблонный ответ |
| Ошибка действия | `action.executed` с `error: {code: "not_found"}`, в трассировке `find_client:error`, бот переспрашивает один раз |
| Срочное при нескольких темах | первым идёт сценарий с `urgency = urgent`, остальные в `dialog.state.stack` с `reason = multi_intent` |
| Второе мнение | `trace.second_opinion` с моделью `gpt-6-sol` и флагом `agreed` |
| Перебивание | `tts.interrupt`, у трассировки хода `interrupted = true` |
| Смена языка по просьбе | `bot.text.final.lang` и `dialog.state.language` меняются, начиная с этого хода |
